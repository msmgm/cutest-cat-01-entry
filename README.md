# Draw the cutest cat — make.fun entry

A cute cartoon kitten (orange-and-white tabby, big eyes, blush, holding a
heart) on a pastel sky with sun, clouds, flowers and floating hearts.

## How it works

- `cat.png` — the picture, drawn procedurally and saved as a 1024×1024 PNG
  (26,739 bytes, under the 1 MiB limit).
- `main.ts` — copies `cat.png` to `/output/entry.png`, byte for byte.
  No network, no randomness, no model calls, so both runs write identical bytes.
